# Mythos Writer 0.5.7

## Features
- **Notes for every level of your book.** The scene notes panel now has separate notes for the Book, each Part, each Chapter and each Scene. Part notes belong to their own book, so two books with a "Part 1" no longer share or mix up notes. In the Notes view, the Properties column now lists Backlinks first, then properties and tags, then Recent notes. (#1648)
- **Agent files in Models & Keys.** Settings → Models & keys shows where your agents' files live, with buttons to reveal the folder, open it, or empty it (it asks before deleting anything). (#1648)
- **One writing partner.** The writing partner is now a single chat with quick actions (Update Timeline, Beta Read, Writer Scan) and uses the name you give your AI. Earlier chats opens your past sessions, and Beta Read runs once per click instead of twice. (#1646)
- **New first-run welcome.** A simpler welcome screen replaces the old setup wizard and Getting Started card, and Mythos now remembers whether you started from a template, a blank vault or an import. (#1646, #1644)
- **Timeline and Realm.** The Timeline adds a closer Month zoom and a folder-style tree in its sidebar, and the Realm view now fits everything on screen when it opens. (#1646)
- **Boards sidebar as a folder tree.** Nested boards are a click or two away, Home stays pinned at the top, and you can drag the sidebar to the width you like. (#1645)
- **Notes open in Rich view.** Notes open in Rich view by default, and Markdown and Source modes are turned on in Settings when you want them. With "Always open in Rich" on (the new default), a note's saved view mode is kept but not used until you turn that option off. Page setup gains zoom presets, and the active tab is outlined more clearly. (#1643)
- **Smoother links and Settings.** Typing `[[` shows suggestions right away, clicking a link to a note that doesn't exist yet creates it, @mentions take you to what they name, and dropping a file into the editor adds a link with its title. Settings now saves on its own when you close it, so there is no Save button. (#1644)

## Fixes
- Restoring a backup no longer wipes your saved AI keys. Before 0.5.7, restoring a backup made before 0.5.4 erased every saved key, and any restore erased the Alpha Reader, Storyline Consultant and Line Editor keys. If your keys went blank after a restore, enter them again once. Backups never contained your keys.
- **Structure and Full Book:** empty parts now show up; you can drag a chapter into a part, add chapters and scenes inside a part, and rename a part from its Full Book heading or the navigator menu. A new chapter goes right after the one you have selected. (#1645)
- **Moving and editing scenes:** text you type right after moving a scene stays with that scene in its new chapter, renaming a part while a save is still going through works, and going Forward brings back the full Continuity note. (#1645)
- **Scene Crafter:** Create Scene now builds a board from what you filled in (goal, conflict, beats, length, tone and references) and opens it, instead of making an empty "Board N". (#1645)
- **Copied stories:** a story folder copied outside Mythos now opens as its own story with its own text. Before, the copy could show the original's text, typing in one could save into the other, or the copy stayed hidden until you rebuilt the vault index. (#1656)
- **Notes search** matches the new look, and the Notes sidebar starts a little wider. A width you already set is kept. (#1655)
- The Notes Brainstorm pane now fits at 900 and 1024 px window widths with no sideways scrolling, and its buttons stay clickable. (#1662)
- **Look and layout:** panel headers line up at one height, glass panels and pop-ups stack correctly, the starry wallpaper is the default, the bottom bar spans the full window, and Brainstorm's mode switch is reachable from the ⋯ menu in narrow windows. (#1644)
- If a key field had been saved as its masked preview (for example `sk-ant-…1234`) instead of the real key, Settings now marks it as missing and asks you to enter the key again. Pasting a masked preview into a key field shows an error instead of saving it. (#1660)

## Security & dependencies
- **AI keys are stored encrypted.** Every saved key, including the Alpha Reader, Storyline Consultant and Line Editor keys, now lives in your system's secure storage instead of in plain text in the settings file. Keys saved by older versions move over on the next start, and the settings file is written in a way that a crash mid-save can't leave it half-written. (#1661)
- Updated the `brace-expansion` package to address a high-severity security advisory. (#1652)

## Known issues
- Vaults created before 0.5.7 keep the old, reversed Timeline order. An opt-in fix is planned.
- In Settings, the **Move…** button in the agents' files section doesn't move anything yet.
- Part notes that were saved only under a plain "Part N" name, with no book, no longer show. The notes are still on disk, untouched.
- A chapter copied within the same story may stay hidden until you use **Rebuild**.
- If you switch vaults while Settings is open, the key preview can keep showing the previous vault's key status until you close and reopen Settings. Your saved keys aren't affected.
- On systems without a working keychain (mostly Linux without a keyring), API keys aren't kept between restarts, so the key fields are blank after a restart. If an older version saved a key in plaintext, it stays in the settings file until you save Settings once; that first save removes it. To remove it right away, open Settings and close it again (closing Settings saves).
- If Mythos can't write its settings file (for example, its settings folder is read-only), Settings won't close and shows "Couldn't save settings. Try again." Make the folder writable again, then press Close.
- If you go back to 0.5.6, the Alpha Reader, Storyline Consultant and Line Editor keys will look empty. They're still saved, and they come back when you update to 0.5.7 again. If you enter a key for one of those helpers while on 0.5.6, 0.5.6 saves it unencrypted, the way it always has, and 0.5.7 encrypts it the next time it starts.
- At narrow window widths (around 900 px), the left navigation rail can overlap the content next to it by a few pixels.
- If the left pane was saved at its widest (500 px), it can still cut off content at window widths of 900–1024 px.
